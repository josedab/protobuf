===============================================================================
DEPENDENCY RESOLUTION STRATEGY
===============================================================================

Bazel MVS (Minimum Version Selection):
  - Highest version across all dependencies wins
  - Lock files: maven_install.json, maven_dev_install.json
  - Bzlmod: Single version override for apple_support

Maven:
  - protobuf-bom manages version inheritance
  - Test dependencies scoped separately
  - Transitive dependency management via Guava

Python:
  - Upper bounds pinning
  - absl-py: major version 2.x
  - numpy: upper bound <= 2.3.4
  - setuptools: upper bound <= 78.1.1
