# Getting Started

Welcome to Protocol Buffers! This section will help you get up and running quickly.

## What You'll Learn

- How to install the Protocol Buffer compiler and runtime libraries
- How to define your first `.proto` file
- How to generate and use code in your preferred language

## Prerequisites

Before you begin, you should have:

- Basic programming knowledge in your target language
- A development environment set up (compiler, IDE, etc.)
- Command-line familiarity

## Quick Start Path

1. **[Installation](installation.md)** - Install the Protocol Buffer compiler (`protoc`) and runtime libraries
2. **[Quick Start](quickstart.md)** - Create your first protocol buffer message
3. **[Next Steps](next-steps.md)** - Explore more advanced topics

## Choosing a Language

Protocol Buffers officially supports:

| Language | Runtime | Code Generator |
|----------|---------|----------------|
| C++ | Built-in | Built-in |
| Java | Built-in | Built-in |
| Python | Built-in | Built-in |
| Go | [google.golang.org/protobuf](https://pkg.go.dev/google.golang.org/protobuf) | [protoc-gen-go](https://pkg.go.dev/google.golang.org/protobuf/cmd/protoc-gen-go) |
| C# | [Google.Protobuf](https://www.nuget.org/packages/Google.Protobuf) | Built-in |
| Ruby | [google-protobuf](https://rubygems.org/gems/google-protobuf) | Built-in |
| Objective-C | Built-in | Built-in |
| PHP | [google/protobuf](https://packagist.org/packages/google/protobuf) | Built-in |

## Time Estimate

- **Installation**: 5-10 minutes
- **Quick Start Tutorial**: 15-20 minutes
- **Basic proficiency**: 1-2 hours
